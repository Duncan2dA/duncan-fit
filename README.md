# Duncan Fit

Een persoonlijke, offline bruikbare trainings-PWA voor een veilige terugkeer naar krachttraining en spieropbouw.

## Inhoud

- 12 weken met opbouw- en herstelweken
- vier trainingen per week
- logging van gewicht, herhalingen en voltooide sets
- vorige trainingsgewichten en trainingsvolume
- ingebouwde rusttimer
- lokale opslag, export en import van een reservekopie
- mobiel ontwerp voor iPhone en iPad
- offline app-shell via een service worker

## Lokaal bekijken

Start een eenvoudige webserver in deze map en open de getoonde URL. Een webserver is nodig om de service worker en installatiefunctie te testen.

## Publicatie

Een push naar `main` start `.github/workflows/pages.yml`. De live app staat daarna op:

<https://duncan2da.github.io/duncan-fit/>

Train pijnvrij en stop bij scherpe pijn, instabiliteit of toenemende zwelling. De app vervangt geen persoonlijk medisch advies.
